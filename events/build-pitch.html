About the Event

Build & Pitch is a system design challenge that tests participant's ability to analyse a real-world problem, design a scalable software solution, develop a prototype, and effectively communicate their engineering decisions.

Think. Design. Prototype. Pitch.

Event Structure

  • Prelims Screening: MCQs, 10 mins evaluating system design concepts.
  • Mains Sprint: 6 hours Prototype Challenge.
  • A problem statement relevant to current societal, industrial, or technological challenges will be given to participants at the beginning of the event.
  • A batch should contain 4 members strictly.
  • Four systems will be provided to a batch.
  • The members of a batch will go for lunch one by one for half an hour.

Eligibility

  • Team size: 4 members.
  • Participants can be from any department and any college.
  • Cross-department and cross-college teams are permitted.
  • One participant can be part of only one team.

Expected Project Deliverables

  1. Project Title and Abstract (System Overview)
  2. High Level Design
    • Requirement Specification (functional & non-functional)
    • System architecture diagram
    • Modules description
    • Technology stack
    • Database overview
    • Deployment architecture
  3. Low Level Design
    • Architecture diagram
    • Database Schema
    • API Specifications
    • Algorithms & logic
    • Error Handling
  4. Implementation Details & Results

General Rules

  1. Each team must consist of 4 members strictly and 4 desktop systems will be provided for each team.
  2. Free internet access will be available throughout the event.
  3. The problem statement will be disclosed only at the start of the Mains.
  4. Teams are expected to create original solutions during the event. Pre-built solutions and existing GitHub repos for the same problem are not permitted.
  5. Judges' decisions will be final and binding.
  6. Any form of plagiarism or unfair means may lead to disqualification.
