About the Event

Query Masters is a two-round DBMS technical event designed to test participant's conceptual understanding of Database Management Systems as well as their practical, hands-on SQL query-writing ability. The event progresses from a knowledge-based screening round to a high-intensity, hands-on SQL problem-solving round.

Key Event Highlights

  • Round 1 (Prelims): 10-minute written/on-screen quiz covering core DBMS concepts & normalization.
  • Round 2 (Mains): 3-hour hands-on SQL challenge solving complex queries on live database schemas.
  • Focus Areas: JOINS, subqueries, aggregation, ACID properties, indexing, and edge-case handling.
  • Team Dynamics: Compete in teams of 2 members to demonstrate query optimization & teamwork.

Prelims — DBMS Quiz

The Prelims round is a written/on-screen quiz conducted in the computer labs to test conceptual clarity in DBMS. This round acts as a filter to shortlist participants for the hands-on SQL Challenge in Mains.

Duration: 10 minutes

Topics Covered

  • Normalization (1NF, 2NF, 3NF, BCNF) and Functional Dependencies
  • SQL Fundamentals: DDL, DML, DCL, TCL Commands
  • ACID Properties: Atomicity, Consistency, Isolation, Durability
  • Keys: Primary, Foreign, Candidate, Composite Keys
  • Transactions, Concurrency Control, and Indexing Basics

Format & Rules

  • Conducted as an objective/short-answer quiz (MCQ + short conceptual questions).
  • No use of mobile phones, notes, or external help during the quiz.
  • Top-performing participants (based on predefined cutoff/ranking) qualify for Mains.
  • In case of a tie, an additional tie-breaker question may be used.

Mains — SQL Challenge

The Mains round is a hands-on, computer-based challenge where shortlisted participants solve real SQL problems on a provided database schema. The focus is on writing correct, efficient queries and handling tricky edge cases.

Duration: 3 Hours

Topics Covered

  • JOINS: INNER, LEFT, RIGHT, SELF, and Multi-table Joins
  • GROUP BY, HAVING, and Aggregate Functions (COUNT, SUM, AVG, MAX, MIN)
  • Subqueries, Nested Queries, and Correlated Queries
  • Logical Query Building for Real-world Business Problems
  • Handling NULL values, Duplicates, and Other Edge Cases

Format & Rules

  • Participants attempt queries directly on lab systems using the provided DBMS tool (MySQL / Oracle / PostgreSQL: to be finalized).
  • A schema with sample tables and data will be shared at the start of the round.
  • Marks are awarded per query based on correctness, efficiency, and handling of edge cases.
  • Partial marking may apply for queries that are logically correct but not fully optimized.
  • Any attempt to copy or share queries between participants leads to immediate disqualification.

Evaluation Criteria

  • Query Correctness: 50%
  • Handling of Edge Cases: 20%
  • Query Efficiency / Optimization: 15%
  • Time Taken to Complete: 15%

General Rules

  1. Team participation only.
  2. Valid college/institution ID is mandatory.
  3. Participants must report at least 15 minutes before the event.
  4. Mobile phones, smart devices, notes, or any external resources are strictly prohibited.
  5. Judges' decisions regarding evaluation and qualification are final.
  6. Any malpractice, plagiarism, or copying of SQL queries will result in immediate disqualification.
