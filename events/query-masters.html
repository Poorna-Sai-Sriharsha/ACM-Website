Query Masters

DBMS Technical Event

Organized by ACM Student Chapter · R.V.R. & J.C. College of Engineering, Guntur

✦ Query. Optimize. Win. ✦
Category DBMS – Technical Event
Team Size 2 Members per Team
Prelims DBMS Quiz — 11th August 2026, 8:00 AM - 12:00 PM
Mains SQL Challenge — 11th August 2026, 1:00 PM - 4:00 PM
Venue C3 Lab

About the Event

Query Masters is a two-round DBMS technical event designed to test participants' conceptual understanding of database management systems as well as their practical skills in database design and SQL query-writing. The event progresses from a knowledge-based screening round to a high-intensity, hands-on Schema Forge round where teams design a complete database from a real-world scenario and solve queries on it.

Key Event Highlights

  • Round 1 (Prelims): 10-minute written/on-screen quiz covering core DBMS concepts & normalization.
  • Round 2 (Mains): 3-hour hands-on SQL challenge solving complex queries on live database schemas.
  • Focus Areas: JOINS, subqueries, aggregation, ACID properties, indexing, and edge-case handling.
  • Team Dynamics: Compete in teams of 2 members to demonstrate query optimization & teamwork.

Prelims — DBMS Quiz

The Prelims round is a written/on-screen quiz conducted in the computer labs to test conceptual clarity in DBMS. This round acts as a filter to shortlist participants for the hands-on SQL Challenge in Mains.

Duration: 10 minutes

Topics Covered

  • Normalization (1NF, 2NF, 3NF, BCNF) and Functional Dependencies
  • SQL Fundamentals: DDL, DML, DCL, TCL Commands
  • ACID Properties: Atomicity, Consistency, Isolation, Durability
  • Keys: Primary, Foreign, Candidate, Composite Keys
  • Transactions, Concurrency Control, and Indexing Basics

Format & Rules

  • Conducted as an objective/short-answer quiz (MCQ + short conceptual questions).
  • No use of mobile phones, notes, or external help during the quiz.
  • Top-performing participants (based on predefined cutoff/ranking) qualify for Mains.
  • In case of a tie, an additional tie-breaker question may be used.

Mains — SQL Challenge

The Mains round is a hands-on, computer-based challenge where shortlisted participants solve real SQL problems on a provided database schema. The focus is on writing correct, efficient queries and handling tricky edge cases.

Duration: 3 Hours

Topics Covered

  • Database Design from a Real-World Scenario
  • Creating Databases and Tables (CREATE DATABASE, CREATE TABLE)
  • Defining Primary Keys, Foreign Keys, and Constraints
  • Inserting Sample Data (INSERT INTO)
  • SQL Queries using JOINs (INNER, LEFT, RIGHT, SELF)
  • GROUP BY, HAVING, Aggregate Functions
  • Subqueries and Nested Queries
  • Filtering, Sorting, and Business Logic
  • Handling NULL values, duplicates, and edge cases

Format & Rules

  • Participants will receive a business scenario (e.g., Library Management, Hospital, E-commerce, College Management, etc.).
  • Based on the scenario, participants must:
    1. Design the database schema
    2. Create all required tables with appropriate constraints
    3. Insert the necessary sample data
    4. Solve the SQL query questions provided by the organizers.
  • Participants must use the provided DBMS tool (MySQL / MySQL Server / Oracle PL/SQL / DB2).
  • Duration: 3 hours.
  • Marks will be awarded for correct database design, query accuracy, efficiency, and handling of edge cases.
  • Partial marking may be awarded for logically correct solutions.
  • Any form of copying or sharing solutions will lead to disqualification.

Evaluation Criteria

  • Database Design (Schema, Keys, Constraints): 30%
  • Query Correctness (Accurate Output): 45%
  • Handling Edge Cases (NULLs, Duplicates, Constraints): 15%
  • Query Efficiency & Optimization: 10%

General Rules

  1. Participation is in teams of 2 members; individual entries are not permitted.
  2. Valid college/institution ID is mandatory for registration and entry.
  3. Participants must reach the venue 15 minutes before the reporting time.
  4. Use of mobile phones, smart devices, or external notes is strictly prohibited during both rounds.
  5. Decisions made by the judges/evaluators regarding scoring and qualification are final.
  6. Any form of malpractice (copying, plagiarized queries) will lead to immediate disqualification.
